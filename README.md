# AI Personal Productivity Agent

## Overview

AI Personal Productivity Agent is a GenAI-based application that helps users organize and prioritize their tasks.

The user provides a task or goal, and the AI analyzes it and provides a structured plan with priorities, important concepts, tips, and suggested actions.

## Features

- Task and goal analysis
- Priority-based planning
- Suggested actions
- Important concepts to focus on
- Helpful tips
- Simple and user-friendly interface
- Supports different types of inputs such as study, college, fitness, and personal activities

## Technologies Used

- Python
- Generative AI
- LangChain
- Ollama
- Qwen 2.5 3B
- Streamlit
